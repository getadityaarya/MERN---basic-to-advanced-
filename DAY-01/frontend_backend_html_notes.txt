FRONTEND & BACKEND FUNDAMENTALS + HTML BASICS NOTES

WEB DEVELOPMENT OVERVIEW

Frontend (Client Side) - Deals with everything the user sees and
interacts with inside the browser. - Runs on the browser (Chrome, Edge,
Firefox, etc.)

Responsibilities: - UI design and layout - Styling and components - Data
display - API integration - Routing/navigation - Form validation -
State/data management

Technologies: - HTML - CSS - JavaScript - React / Next.js

Backend (Server Side) - Handles server, database, and business logic. -
Runs on server/system.

Responsibilities: - Database connection and management - Creating REST
APIs - Data validation - Authentication/authorization - Business logic
implementation - Third‑party API integration - Sending data to frontend

Technologies: - Node.js - Express.js - Nest.js - Databases (MongoDB,
MySQL, etc.)

BASIC WEB TERMS

Web Page: - Single HTML file loaded in browser.

Website: - Collection of multiple web pages with a domain/address.

Web App: - Interactive website with logic and database. Examples:
Facebook, Flipkart, Gmail

CORE FRONTEND TECHNOLOGIES

HTML: - Structure of UI (Skeleton)

CSS: - Styling and design (Colors, layout, spacing, animation)

JavaScript: - Dynamic behavior and logic (Brain)

React: - JavaScript library for building component-based UI easily and
efficiently

BACKEND TECHNOLOGIES

Node.js: - Runtime environment to run JavaScript outside the browser

Express.js: - Backend framework for creating servers and APIs

Nest.js: - Structured and scalable backend framework

Next.js: - React framework with routing and server-side rendering
