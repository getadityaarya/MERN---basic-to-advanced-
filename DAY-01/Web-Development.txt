DAY 01 – WEB DEVELOPMENT & HTML FUNDAMENTALS

  ------------------------------------
  1. INTRODUCTION TO WEB DEVELOPMENT
  ------------------------------------

Web development is the process of building websites and web applications
that run inside a browser.

Examples: - Facebook - Flipkart - Gmail - Amazon

These applications allow users to interact with data dynamically.

  --------------------------
  2. TYPES OF APPLICATIONS
  --------------------------

1)  Web App
    -   Runs inside browser
    -   No installation required
    -   Example: Gmail
2)  Standalone Mobile App
    -   Installed from Play Store/App Store
    -   Example: WhatsApp, Instagram
3)  Cross-platform App
    -   Built using React Native / Flutter
    -   Works on Android + iOS

  ---------------------------------
  3. WEB APPLICATION ARCHITECTURE
  ---------------------------------

A web application has 3 main layers:

Frontend → Backend → Database (FE) (BE) (DB)

  ---------------------------
  4. FRONTEND (CLIENT SIDE)
  ---------------------------

Definition: Frontend is the part of the application that users see and
interact with.

Runs on: - Browser

Responsibilities: - Create UI (buttons, forms, pages) - Styling and
design - Data management - API integration - Routing/navigation - Form
validation - Handle user events

Technologies: - HTML - CSS - JavaScript - React / Next.js

  --------------------------
  5. BACKEND (SERVER SIDE)
  --------------------------

Definition: Backend handles logic, processing, and database operations.

Runs on: - Server/System

Responsibilities: - Create REST APIs - Connect database - Data
validation - Authentication - Business logic - Third-party API
integration

Technologies: - Node.js - Express.js - Nest.js - Spring Boot - Django -
Laravel

  ------------------
  6. DATABASE (DB)
  ------------------

Purpose: Stores application data permanently.

Types:

SQL (Relational) - MySQL - Oracle - PostgreSQL

NoSQL - MongoDB

MERN uses MongoDB.

  ----------------------------------
  7. HOW THE WEB WORKS (IMPORTANT)
  ----------------------------------

Request–Response Cycle:

Step 1: User enters URL Step 2: Browser sends request to server Step 3:
Server processes request Step 4: Server sends HTML/CSS/JS Step 5:
Browser renders page

Flow: Browser → Server → Response → Browser renders UI

  --------------------
  8. BASIC WEB TERMS
  --------------------

Web Page: - Single HTML file

Website: - Collection of multiple pages with domain

Web App: - Interactive website with backend + database
